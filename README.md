Study Time Tracker
Program Description
My program gives the user the amount of time they study in a week. This program solves the problem of students not knowing how long they are studying each week and helps them see if they need to increase or decrease their study hours.

How to Run the Program
open python app.py
click the run button
welcome message printed
enter the number of hours the user studies in a day
weekly study hours displayed 

Example Interaction Output
Welcome to my Python program!
How many hours did you study today? 4
You are on track to study 28.0 hours this week.
